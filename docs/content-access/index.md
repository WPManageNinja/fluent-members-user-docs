# Content Access Overview

**Content Access** decides what each Membership Level unlocks. You set it on the level's **Content Access** tab, share sets of content between levels with **Bundles**, and choose what everyone else sees.

## How the pieces fit together

There is no separate Access Groups screen any more. Protection is set in these places:

| Where | What it does |
|---|---|
| **Fluent Members → Membership Levels → (a level) → Content Access** | Sets the content a level unlocks, the memberships it includes, its Bundles, spaces and courses, and a release schedule. See [Content Access tab](/docs/levels/content-access). |
| **Bundles** | A set of content shared by several levels, edited from any level that uses it. See [Bundles](/docs/content-access/bundles). |
| **Fluent Members → Settings → Public content** | Items everyone can see, even when a level would lock them. See [Public content](/docs/content-access/public-content). |
| **Fluent Members → Settings → Restricted content** | The site-wide default for what visitors without access see. See [Restricted content settings](/docs/content-access/restricted-content). |
| **Membership access panel in the editor** | Protects or opens one post. See [Protect a single post](/docs/content-access/per-post-restrictions). |
| **Restricted Content block** | Hides part of a page. See [Restricted blocks](/docs/content-access/gutenberg-block/inserting). |

## Protect content for a level

1. Go to **Fluent Members → Membership Levels** and open the level.
2. Click the **Content Access** tab, then **Add content**.
3. Pick what to protect. [What you can protect](/docs/content-access/protected-content) lists every option.
4. Click **Add (n) items**, then **Save** in the save bar.

![Screenshot of the Content Access tab with the Add content button](/images/content-access/index/content-access-tab-empty.webp)

The content is protected as soon as you save. [How protection works](/docs/content-access/how-protection-works) explains which check decides who gets in.
